# Piors Agent Instructions

These are common instructions for Pior's agents across all scenarios.

## General Guidelines

- Never use em dashes. use plain dashes "-" instead.
- When writing commit messages, NEVER auto-add your agent name as co-author.
- When making technical decision, do not give much weight to development cost.
- Always remember to .gitignore agent repos (eg. .claude, .agents, etc)
- When drafting or writing PRs, NEVER auto-add your agent name
