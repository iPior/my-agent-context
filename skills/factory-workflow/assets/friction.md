# Factory friction log

Coordinator-owned. Record what slowed or confused this run in the factory
skills, contract, helper, or harness. Number entries F-1, F-2, ... and say which
stage they came from. Workers record their own friction in their handoffs;
summarize cross-cutting themes here before the final report. Do not change the
installed skills during a run.

This file feeds the factory's self-improvement loop (coordinator contract,
"Improve the factory"): after the merge, each entry gets a proposed change or a
reason for none, and a draft PR to the skills' source repository addresses the
actionable ones. Write entries so a later reader can act on them: what
happened, what the skill said or left out, and what would have helped.
